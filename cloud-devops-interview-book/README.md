# Cloud Platform & DevOps Interview Book (400 Q&A)

Enriched Word editions generated from `content/source.md`.

## Outputs

- `output/Cloud_Platform_DevOps_Interview_Book_400QA.docx` — clean reading copy
- `output/Cloud_Platform_DevOps_Interview_Book_400QA_Highlighted.docx` — quick-learning copy with yellow highlights on load-bearing sentences

Each question includes:

1. Spoken answer
2. Analogy
3. Production context + extra context
4. Step-by-step path
5. Strong-answer notes
6. Evidence commands
7. Red flag
8. Likely follow-up

Modules open with mindmaps and infographics (vector drawings rasterised into the DOCX).

## Build

```bash
cd cloud-devops-interview-book
pip install -r requirements.txt
python3 build.py
```
